# Vulkan 1.4 Phase 3 — Performance Modernizations

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:
> executing-plans to implement this plan task-by-task.

**Goal:** Adopt the profiler-gated [B] items from `docs/VulkanAudit-2026-07.md` §4 and §5. Only implement a feature if
Tracy/NSight shows ≥10% improvement in a real VoxelLab scene, per `docs/philosophy/93_performance-methodology.md`.

**Architecture:** Phase 3 builds on the spec-clean baseline of Phase 1+2. Each task starts with a reproducible
benchmark, implements the modernization behind a runtime gate, and re-measures. If the win is below 10% or the feature
is too invasive, the task is rolled back and documented.

**Tech Stack:** C++26, Vulkan 1.4, Tracy, NSight Graphics.

## Global Constraints

- Every task must start with a Tracy capture or NSight frame showing the current cost.
- Implementation is gated on ≥10% hot-path improvement in a real scene.
- All changes must still pass `ninja -C build/linux-clang-debug ProjectV` and `ctest`.
- Validation layers remain clean.

### Task 3.1: Push descriptors for per-frame RT/DDGI descriptor updates

**Files:**

- Modify: `src/render/vulkan/VulkanBootstrap.cpp` (enable `pushDescriptor`)
- Modify: `src/render/RayTracedShadowsPass.cpp`, `src/render/RtxGiProbesUpdate.cpp` (use `vkCmdPushDescriptorSetKHR`/
  `vkCmdPushDescriptorSetWithTemplateKHR`)
- Modify: descriptor set layouts where push descriptors are used (add
  `VK_DESCRIPTOR_SET_LAYOUT_CREATE_PUSH_DESCRIPTOR_BIT_KHR`)
- Test: Tracy before/after + validation smoke

- [ ] **Step 1: Benchmark current descriptor-update cost**

Capture a Tracy frame with `PROJECTV_HW_RAY_TRACING=ON` and note `RecordRayTracedShadowPass` / `RtxGiProbesUpdate` CPU
time.

- [ ] **Step 2: Enable `pushDescriptor`**

In `BuildEnabledFeatures14`:

```cpp
enabled.pushDescriptor = selected.features14.pushDescriptor ? VK_TRUE : VK_FALSE;
```

- [ ] **Step 3: Create push-descriptor layouts for RT/DDGI**

For the per-frame descriptor sets, add `VK_DESCRIPTOR_SET_LAYOUT_CREATE_PUSH_DESCRIPTOR_BIT_KHR` at layout creation.

- [ ] **Step 4: Replace `vkUpdateDescriptorSets` + `vkCmdBindDescriptorSets` with `vkCmdPushDescriptorSetKHR`**

Example:

```cpp
VkWriteDescriptorSet write{...};
vkCmdPushDescriptorSetKHR(cmd, VK_PIPELINE_BIND_POINT_COMPUTE, layout, 0, 1, &write);
```

- [ ] **Step 5: Re-measure and gate**

If CPU time in descriptor update drops by <10%, revert and document.

- [ ] **Step 6: Commit**

```bash
git add src/render/vulkan/VulkanBootstrap.cpp src/render/RayTracedShadowsPass.cpp src/render/RtxGiProbesUpdate.cpp
git commit -m "perf(vulkan): push descriptors for RT/DDGI per-frame updates

Profiler-gated: reduces CPU descriptor churn by >=10% in VoxelLab."
```

- [ ] **Step 5: Commit**

### Task 3.4: RT pipeline libraries + deferred host operations

**Files:**

- Modify: `src/render/RtxShadowPipeline.cpp`
- Modify: `src/render/vulkan/VulkanBootstrap.cpp` (ensure `pipelineLibrary` features enabled)
- Test: cold-start timing + validation smoke

- [ ] **Step 1: Measure cold-start RT pipeline compile time**

Use Tracy/NSight to time `vkCreateRayTracingPipelinesKHR`.

- [ ] **Step 2: Split RT pipeline into linked pipeline libraries**

Create separate pipeline libraries for ray-gen, miss, and hit groups, then link them with
`VK_PIPELINE_CREATE_LIBRARY_BIT_KHR` + `VK_PIPELINE_CREATE_RAY_TRACING_SHADER_GROUP_HANDLE_CAPTURE_REPLAY_BIT_KHR` if
stable handles are desired.

- [ ] **Step 3: Use deferred host operations**

Pass a `VkDeferredOperationKHR` to `vkCreateRayTracingPipelinesKHR` and defer compilation to a background thread.

- [ ] **Step 4: Re-measure and gate**

Require ≥10% faster cold start or reduced frame-time stutter.

- [ ] **Step 5: Commit**

```bash
git add src/render/RtxShadowPipeline.cpp src/render/vulkan/VulkanBootstrap.cpp
git commit -m "perf(rtx): pipeline libraries + deferred host ops

Reduces ray-tracing PSO compile stutter."
```

- Modify: `src/render/RayTracedShadowsTlas.cpp` (use `VK_BUILD_ACCELERATION_STRUCTURE_MODE_UPDATE_KHR`)
- Test: Tracy before/after + RTX validation smoke

- [ ] **Step 1: Benchmark TLAS rebuild cost**

Measure `vkCmdBuildAccelerationStructuresKHR` for TLAS each frame.

- [ ] **Step 2: Enable BLAS updates**

Add `VK_BUILD_ACCELERATION_STRUCTURE_ALLOW_UPDATE_BIT_KHR` to BLAS build flags.

- [ ] **Step 3: Refit TLAS when only transforms changed**

When chunk geometry is static, call `vkCmdBuildAccelerationStructuresKHR` with
`mode = VK_BUILD_ACCELERATION_STRUCTURE_MODE_UPDATE_KHR`.

- [ ] **Step 4: Re-measure and gate**

Require ≥10% reduction in TLAS build time.

- [ ] **Step 5: Commit**

```bash
git add src/render/RayTracedShadowsBlas.cpp src/render/RayTracedShadowsTlas.cpp
git commit -m "perf(rtx): refit TLAS when geometry is static

Avoids full rebuild when only instance transforms change."
```
