# Vulkan 1.4 Phase 4 — Hardware-Gated Future Options

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:
> executing-plans to implement this plan task-by-task.

**Goal:** Track the [C] items from `docs/VulkanAudit-2026-07.md` §4.4 and §4.1 that depend on specific driver/GPU
support or asset changes. These are not blockers for the Vulkan 1.4 cleanup; they are future capabilities to enable when
hardware/assets justify them.

**Architecture:** Each task is a standalone probe → gate → integration. Implement only if the feature is supported on
the target RTX hardware and the relevant subsystem (meshes, textures, frame pacing, etc.) needs it.

**Tech Stack:** C++26, Vulkan 1.4 + optional KHR/EXT extensions, NVIDIA RTX 20/30/40/50 series.

## Global Constraints

- No task in this phase may regress Phase 1/2 correctness or validation cleanliness.
- Each task must probe feature support at startup and cleanly disable itself when unsupported.
- All changes pass `ninja -C build/linux-clang-debug ProjectV` and `ctest`.

### Task 4.1: Bindless descriptors

**Files:**

- Modify: `src/render/vulkan/VulkanBootstrap.cpp` (query `VkPhysicalDeviceDescriptorIndexingFeatures`)
- Modify: descriptor set layouts across `src/render/vulkan/*Pipeline*.cpp` to use unbounded arrays
- Modify: shaders to use `layout(set=0, binding=N) type array[];`
- Test: validation smoke + performance measurement

- [ ] **Step 1: Probe descriptor indexing caps**

Query `descriptorIndexing`, `runtimeDescriptorArray`, `descriptorBindingPartiallyBound`,
`descriptorBindingVariableDescriptorCount`, `descriptorBindingSampledImageUpdateAfterBind`, etc.

- [ ] **Step 2: Create bindless descriptor set layout**

Use `VK_DESCRIPTOR_BINDING_PARTIALLY_BOUND_BIT` and `VK_DESCRIPTOR_BINDING_VARIABLE_DESCRIPTOR_COUNT_BIT` for the last
binding.

- [ ] **Step 3: Migrate 1:1 bindings to bindless arrays**

Start with the graphics descriptor set (textures, SSBOs). Update shaders and C++ descriptor writes.

- [ ] **Step 4: Validate and measure**

Run validation smoke and a draw-count benchmark. Commit only if stable.

- [ ] **Step 5: Commit**

```bash
git commit -m "feat(vulkan): bindless descriptor arrays

Enables unbounded resource arrays per docs/philosophy/31_vulkan.md."
```
