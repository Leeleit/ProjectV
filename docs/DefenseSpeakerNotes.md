## §2. Vulkan 1.4 + C++26 — 1 минута

**Участник 2**

Меня зовут [имя], я расскажу про технологический стек ProjectV.

Vulkan 1.4 — это низкоуровневый графический API, который даёт явный контроль над GPU. В
ProjectV мы используем динамический рендеринг, per-image submit semaphores, compute-конвейеры
для генерации мешей и ray-marching. Слои валидации включены в debug-пресете и ловят
ошибки до запуска.

C++26 — это последний стандарт на 2026 год. В нашем коде активно используются `std::expected`
для обработки ошибок вне горячего пути, `std::simd` для горячих вычислений, модули, концепты,
`constexpr` для проверок на этапе компиляции. В Tier 0 мы ввели `alignas 16` для Vec3/Vec4/Mat4,
что даёт авто-векторизацию в movaps/vmovaps.

Стек компиляции: Clang 22.1.6, CMake 3.30+, Ninja 1.13, ccache для инкрементальной
сборки. Многоплатформенность: Windows через clang-cl 22, Linux через нативный clang 22 с
libc++ (мигрировали с libstdc++ в Tier 2.5). Обе платформы build green, ctest 12/12.

Submodules: 22 зависимости, все с закреплёнными SHA. Это SDL3, volk, VMA, Jolt, Flecs, fastgltf,
Draco, meshopt, miniaudio, fmt, glm, Tracy, imgui, rmlui, freetype, zstd, glaze, slang.

## §3. Voxel-мир + greedy meshing — 1 минута

**Участник 3**

Меня зовут [имя], я расскажу про voxel-мир и meshing.

Voxel-мир в ProjectV организован в чанки — 8×8×8 вокселей на чанк. Всего 27 чанков
для сцены Voxel Laboratory. Каждый чанк может быть dirty (требует ремеша) или чистым.

Greedy meshing — это алгоритм, который объединяет соседние грани одинакового материала
в один quad. 6 проходов на чанк: X+, X-, Y+, Y-, Z+, Z-. Каждый проход обходит 2D-плоскость
extentU × extentV, ищет максимальный прямоугольник, помечает посещённые, повторяет.
Откат к per-voxel для чанков > 64 вокселей. Сокращение количества граней: 30-50% на
чанкованных сценах.

VoxelRaycast — DDA-трассировка луча через чанки для размещения и выделения. Voxel
interaction — CPU авторитетный через `SetVoxelMaterial`, помечает грязные чанки, синхронизирует
физику.

Frustum culling — SIMD frustum cull через `std::simd` и C/AVX2 ядро (Tier 3), тестирует
AABB чанка против 6 плоскостей фрустума за один проход. Двухуровневый кеш — splitmix64
hash от квантованной позиции камеры, при попадании в кеш memcpy вместо 1500 dot products.
Это ускорение в 8 раз по нашим измерениям.

## §4. Шейдеры: CSM, TAA, AOCC — 1 минута

**Участник 4**

Меня зовут [имя], я расскажу про тени, TAA и шейдеры.

Путь теней: 4-каскадные CSM с массивом глубины 2048×2048. Per-cascade view matrix и
ортогональная проекция. Масштабирование смещения получателя по N·L. Взвешенный 5×5 PCF,
с учётом N·L, полоса плавного перехода между каскадами. Покрытие кастерами через
вытеснение среза получателей вверх по направлению солнца.

Контактные тени (CTSH) — DDA-трассировка от фрагмента к солнцу, ограниченный прямой
шейдерный проход. Ambient occlusion (AOCC) — короткая DDA по полусфере, локальный
член видимости. Локальный точечный свет — обратно-квадратичное затухание, член видимости
DDA только для непрозрачных.

TAA — временное сглаживание, включено по умолчанию. 8-точечный jitter Halton, YCoCg-зажим
для цветовой истории, neighbourhood radius 1-7, инвалидация истории по 7 триггерам
(изменение размера swapchain, перезагрузка мира, переключение TAA, изменение jitter scale,
изменение blend, изменение radius, ручная инвалидация). Встроенный CAS после TAA — high-pass
через 4-угловое среднее, вес от (1-blend)*max. B10G11R10_UFLOAT цвет сцены — 2× экономия
пропускной способности против R16G16B16A16.

Горячая перезагрузка шейдеров — F5 перекомпилирует все .spv и пересоздаёт конвейер без
перезапуска приложения. Полезно для итераций только с шейдерами.

## §5. Физика + walk controller — 1 минута

**Участник 5**

Меня зовут [имя], я расскажу про физику и walk controller.

Физика построена на Jolt — это высокопроизводительный движок для твёрдых тел. В ProjectV
мы используем Jolt для обнаружения столкновений и контроллера персонажа. Персонаж
использует CharacterVirtual как прокси/носитель стойки, но владение грунтом
авторится через voxel-решатель в `PhysicsWorld.cpp`.

Walk controller — режим ходьбы с непрерывной выборкой опоры под стопой. Edge grace
для тонких граней. Sneak (Shift) с sampled top-plane поддержкой, без фальшивого
прилипания к стене. Контроль в воздухе — MinecraftLike (по умолчанию) или Realistic
(с фиксацией направления). Авто-прыжок через J, F12 — задержка вкл/выкл. Удержание Space
даёт повторный прыжок после возврата в grounded-подобное состояние.

Три режима управления: walk (физика с грунтом, по умолчанию), creative (полёт с
поддержкой столкновений, с подшагами для высокой скорости), spectator (noclip, игнорирует
паузу). F4 переключает все три режима, двойное нажатие Space переключает creative ↔ walk.

Отладочные клавиши: `[` / `]` — замедление 0-4x, `\` — покадровый шаг (один фиксированный тик),
`` ` `` — сброс к 1x. Переопределение аккумулятора покадрового шага = `fixedSimulationDeltaSeconds`.
Пауза и timeScale=0 — разные оси, не сливаются.

Запросы столкновений с вокселями — интеграция Jolt с VoxelWorld для проверки перед
редактированием (отказ-до-мутации) и синхронизации после редактирования.

## §6. Демо-сцена Voxel Laboratory — 1 минута

**Участник 6**

Меня зовут [имя], я расскажу про демо-сцену «Voxel Laboratory».

Это сцена, которую вы видите на экране. Пол — шахматная доска 18×18 вокселей,
чередующиеся белый и светло-серый. В центре — стеклянный шар радиуса 5 вокселей
с жидкостью внутри. Справа — непрозрачный якорь из FloorGray/FloorWhite для
стабильных кастеров теней от солнца.

Сцена процедурно генерируется при старте за 200 мс. ~13 824 вокселей в 27 чанках (3×3×3,
chunkSize=8), индексированных плоским массивом. Пол Y=0, центр сферы (0, 8, 0).

Четыре фазы демо (по сценарию `legacy/docs/architecture/academic/02_mvp_defense demo.md`):
статичный облёт (камера вокруг сферы), физическое разрушение (снаряд + Jolt),
симуляция жидкости (клеточный автомат), стресс-тест (полное разрушение).
В рамках 10-минутной защиты показываем фазы 1 и 2.

Метрики: FPS 110-130, время кадра 7-9 мс, draw calls 12, память 256 МБ, всё
видно в рантайме в HUD и захватах sidecar под
`build/linux-clang-debug/lookdev-captures/`.
