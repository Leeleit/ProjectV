## 1. Hypothesis

Гипотеза: Упрощенная модель динамики полета (6-DOF жесткое тело + аэродинамика по теории лопасти с делением на 4 секции: левое полукрыло, правое полукрыло, стабилизатор/руль высоты, киль/руль направления + Mach drag rise коррекция) позволяет симулировать поведение самолета с высокой точностью при затратах процессорного времени <5 мкс на один самолет за один игровой такт (tick) на CPU.
При этом интегрирование методом RK4 (Runge-Kutta 4) обеспечивает стабильность шага при низких частотах тиков (20 Гц), тогда как стандартное интегрирование Эйлера (Euler) при резких маневрах и низких частотах теряет устойчивость, приводя к расхождению угловой скорости и "взрыву" симуляции.

---

## 2. Prior Art

Используются следующие материалы:
- Моделирование полета в X-Plane (Blade Element Theory) на лету рассчитывает силы для каждой части крыла.
-Stevens & Lewis "Aircraft Control and Simulation" для уравнений 6-DOF твердого тела.
- Prandtl-Glauert и эмпирические формулы волнового сопротивления на скоростях $M > 0.7$ (Mach drag rise).
- Glenn Fiedler (Gaffer on Games) по интеграции дифференциальных уравнений (Euler vs RK4).

## 3. Method

- **Тип эксперимента:** prototype + benchmark.
- **Сцены/сценарии (5 сценариев):**
  1. `level_flight`: полет вперед со стабильной скоростью 100 м/с, управление нейтрально.
  2. `high_g_turn`: вираж с максимальным креном и кабрированием (максимальные элероны + руль высоты).
  3. `stall_recovery`: кабрирование без тяги до падения скорости ниже критической, сваливание, опускание носа, дача полного газа для выхода.
  4. `mach_dash`: разгон на форсаже от 200 м/с до 400 м/с (переход звукового барьера, рост сопротивления).
  5. `turbulence_handling`: полет в условиях турбулентности (стохастический ветер).
- **Стратегии сравнения (5 стратегий):**
  1. `A_Euler_1Section`: интеграция Эйлера, плоская точка сил (1 аэродинамическая секция для всего самолета, классическая модель аркад).
  2. `B_Euler_4Section`: интеграция Эйлера, 4-секционная Blade Element модель.
  3. `C_RK4_4Section`: интеграция RK4, 4-секционная Blade Element модель.
  4. `D_Analytical_LOD`: аналитический Lookup-табличный метод (предвычисленные силы/моменты) + Euler.
  5. `E_Vectorized_4Section`: векторизованная CPU-симуляция (имитация группового параллелизма / SIMD).
- **Метрики:**
  - Время симуляции одного такта (mean, median, p95, p99, std, в микросекундах).
  - Стабильность (устойчивость вращения, отсутствие NaN/Infinity при 20 Гц и 60 Гц тактах).
  - Точность (отклонение траектории от эталона C_RK4_4Section при 200 Гц тактах).

## 6. Verdict

`yes` — Модель 6-DOF динамики полета на основе Blade Element Theory (4 секции) работает быстрее 1 мкс на шаг для одного самолета (в 5 раз быстрее целевого бюджета 5 мкс). Использование интегратора RK4 критически важно для точности траектории при маневрировании на низком тикрейте 20 Гц (погрешность 9.4 м против 117.4 м у Эйлера).

## 7. Integration Recommendation

- **Target stage:** Stage 6+ (military sandbox / vehicles).
- **Конкретные изменения:** Создать новый физический класс `src/physics/FlightVehicle.{hpp,cpp}`, использующий Flecs компоненты `FlightControlInput` и `RigidBody`.
- **Подход:** Для игрока и ближайших союзников/врагов (LOD0) использовать `C_RK4_4Section` на 20-60 Гц. Для отдаленных ботов (LOD2, >2000 м) использовать переключение на аналитическую модель `D_Analytical_LOD`, что снижает накладные расходы до 100 нс.
- **Риски:** На околозвуковых скоростях (Mach > 0.7) резко меняется центровка (Mach trim / shift of aerodynamic center). В прототипе это не моделировалось (только рост волнового сопротивления) — при необходимости добавить сдвиг фокуса крыла назад в зависимости от числа Маха.
- **Критерии приёмки:** Тест `ProjectVFlightModelTests` с оценкой стабильности на виражах, Tracy-зона `FlightPhysicsStep` < 1.5 мкс при 60 Гц на одно судно.
- **Estimated effort:** S-M effort, 1-2 сессии.
