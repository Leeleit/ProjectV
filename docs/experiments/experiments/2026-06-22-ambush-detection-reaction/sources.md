## Tier 1 — Canonical sources (Wikipedia canonical pages)

### 1. Wikipedia — "Anomaly detection"
- **URL:** https://en.wikipedia.org/wiki/Anomaly_detection
- **Captured:** 2026-06-22
- **Key facts:**
  - Definition (Hawkins 1980): "an outlier is an observation which deviates so much from the other observations as to arouse suspicions that it was generated by a different mechanism"
  - 3 broad categories: Supervised / Semi-supervised / Unsupervised
  - Statistical methods: Z-score, Tukey's range test, Grubbs's test
  - Density-based: k-NN, LOF (Local Outlier Factor), Isolation Forest
  - Neural networks: autoencoders, LSTM, SRUs, foundation models
  - Applications: cybersecurity, video surveillance, IoT, IT infrastructure, petroleum industry
- **Foundation for:** A_NoDetection baseline + B_SimpleThreshold (statistical Z-score analog) + D_BayesianSurprise (anomaly detection as density-based surprise).

### 2. Wikipedia — "Kullback–Leibler divergence"
- **URL:** https://en.wikipedia.org/wiki/Kullback%E2%80%93Leibler_divergence
- **Captured:** 2026-06-22
- **Key facts (canonical formula):**
  - **Definition:** `D_KL(P||Q) = Σ_x P(x) log(P(x)/Q(x))` (asymmetric statistical distance)
  - Non-negative, `D_KL = 0` iff `P = Q` (almost everywhere)
  - **Bayesian updating interpretation:** "D_KL(P||Q) is a measure of the information gained by revising one's beliefs from the prior probability distribution Q to the posterior probability distribution P"
  - Introduced by Solomon Kullback & Richard Leibler 1951 ("mean information for discrimination between H_1 and H_2")
  - Asymmetric — **important for surprise metric** (one-sided KL = P_log(P/Q), not P_log(Q/P))
  - Jeffreys divergence = symmetrized J(1,2) = I(1:2) + I(2:1) (Harold Jeffreys 1948)
  - Fisher information metric = Hessian of relative entropy on parameter space
  - Units: nats (natural log) or bits (log base 2)
- **Foundation for:** D_BayesianSurprise strategy (KL divergence between per-sector prior vs observed posterior).

### 3. Wikipedia — "Behavior tree (artificial intelligence, robotics and control)"
- **URL:** https://en.wikipedia.org/wiki/Behavior_tree_(artificial_intelligence,_robotics_and_control)
- **Captured:** 2026-06-22
- **Key facts:**
  - **Mathematical state space:** `T_i = {f_i, r_i, Δt}` per Colledanchise 2014 (f = vector field, r = return status Running/Success/Failure, Δt = time step)
  - Control flow nodes: Selector (fallback) — first child that does not fail / Sequence — first child that does not succeed
  - **Event-driven BT** (Wikipedia §Background): "behavior trees solved some scalability issues of classical behavior trees by changing how the tree internally handles its execution, and by introducing a new type of node that can react to events and abort running nodes"
  - **Champandard & Dunstan 2012** cited (Game AI Pro Ch.6 "The Behavior Tree Starter Kit", [PDF](http://www.gameaipro.com/GameAIPro/GameAIPro_Chapter06_The_Behavior_Tree_Starter_Kit.pdf))
  - Colledanchise 2018 book (arXiv:1709.00084), Agis 2020 ESWA event-driven BT extension
  - Production: Halo, Bioshock, Spore
- **Foundation for:** E_BayesianPlusBTPriorityInterrupt strategy (BT halt node + priority interrupt = event-driven BT pattern per Champandard 2012 + Isla 2005 GDC).

### 4. Wikipedia — "Bayesian inference"
- **URL:** https://en.wikipedia.org/wiki/Bayesian_inference
- **Captured:** 2026-06-22
- **Key facts:**
  - **Bayes' theorem:** `P(H|E) = P(E|H) × P(H) / P(E)`
  - Posterior ∝ Likelihood × Prior (Evidence normalizer)
  - Cromwell's rule: avoid 0/1 prior probabilities (use bounded priors)
  - Conjugate priors for analytic posterior computation
  - Bayesian updating: dynamic analysis of sequence of data = foundational for sequential surprise detection
- **Foundation for:** D_BayesianSurprise (Bayesian prior/posterior framework) + E_BayesianPlusBTPriorityInterrupt (BT reaction on posterior surprise).
