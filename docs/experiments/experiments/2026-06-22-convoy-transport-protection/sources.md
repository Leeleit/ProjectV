# Sources — convoy-transport-protection

## Games / simulations (convoy AI behaviour)

1. **Foxhole Wiki — Logistics**
   - https://foxhole.wiki.gg/wiki/Logistics
   - Describes Foxhole's player-driven supply convoy mechanics, partisan
     ambushes, route planning.

2. **Bohemia Forums — Convoy behaviour and path planning** (Arma 3)
   - https://forums.bohemia.net/forums/topic/237002-convoy-behaviour-and-path-planning/
   - AI formation driving, push-through on contact, disembark on fire.

3. **DCS TROOP-TRANSPORTS** (GitHub)
   - https://github.com/SinistralValkyries/DCS-TROOP-TRANSPORTS
   - Troop transport helicopter & ground convoy AI, random direction movement
     after disembark.

## Academic / research

4. **AutoGators — Autonomous Convoy Path Planning** (University of South
   Florida)
   - https://github.com/CUTR-at-USF/AutoGators
   - Drone threat detection, dynamic rerouting, path planning for autonomous
     convoys.

5. **DRAIDIS Convoy Route Protection System** (TacticalEdge AI)
   - https://github.com/TacticalEdge/convoy-route-protection-system-draidis
   - Military IED detection algorithms, threat heatmaps, alternate route
     suggestions.

6. **arXiv 1208.5537 — Planning random path distributions for ambush games**
   - https://arxiv.org/abs/1208.5537
   - Game-theoretic model: defender picks path, attacker sets ambush;
     Nash-equilibrium.

7. **IEEE RA-L 2025 — Synchronized task formulation for robotic convoy
   operations**
   - https://ieeexplore.ieee.org/xpl/RecentIssue.jsp?punumber=7083369
   - Synchronized control for multi-robot convoy with constraints.
