## 2. Что говорить дословно (~150 русских слов, 1:30)

> «Воксельный мир в ProjectV разбит на регулярные кубики — чанки (chunk) — размером 8 на 8 на 8 вокселей каждый. Воксели хранятся в одном плоском массиве, не разбросаны по чанкам. На эталонной сцене Voxel Laboratory — 27 чанков, куб 3 на 3 на 3.
>
> У нас 5 материалов: воздух, стекло, жидкость, белый пол и серый пол. Для физики твёрдые три: стекло, белый пол, серый пол. Воздух и жидкость проходимые. Стекло не отбрасывает тени, жидкость — отбрасывает, это явно зафиксировано в наших решениях.
>
> Главный алгоритм — жадный мешинг (greedy meshing) по Лысенкову. Он склеивает соседние грани одного материала в один четырёхугольник. На каждый чанк делается 6 проходов: плюс-икс, минус-икс, плюс-игрек, минус-игрек, плюс-зет, минус-зет. Это сокращает число граней на 30–50 процентов.
>
> Отсечение невидимых чанков — двухуровневый кэш: при статичной камере готовые команды отрисовки просто копируются, фрустум-кулинг запускается только при промахе. Передаю слово.»

---

## 3. Понятия (8 терминов)

| Термин | Что это |
|---|---|
| Воксель (voxel) | Кубический элемент объёма, 1 байт (код материала) |
| Чанк (chunk) | Куб 8×8×8 = 512 вокселей, плоский массив |
| Жадный мешинг (greedy meshing) | Склеивание соседних граней одного материала в один quad |
| Quad (четырёхугольник) | 2 треугольника, минимальная единица грани |
| Материал | Число 0–4 (воздух/стекло/жидкость/белый/серый) |
| AABB (axis-aligned bounding box) | Ограничивающий параллелепипед, выровненный по осям |
| Фрустум-кулинг (frustum culling) | Отсечение объектов вне пирамиды видимости камеры |
| Двухуровневый кэш | Hash + команды отрисовки для быстрого пропуска cull |

1. **Камера на стартовой позиции** — видно сцену VoxelLab, 27 чанков, пол-шахматка, шар, жидкость.
