## 2. Что говорить дословно (~150 русских слов, 1:30)

> «Мы используем C++26 и Vulkan 1.4. Компилятор — Clang 22.1.6, на Linux работает со стандартной библиотекой libc++ 16, на Windows — clang-cl. Сборка через CMake 4.0: 7 отладочных пресетов и 8 релизных. В релизной сборке используем -O3 и тонкий LTO (link-time optimization). Мы сознательно не используем флаг -ffast-math — он ломает детерминизм жидкости и цветовой зажим в TAA. Также нет -march=native, чтобы бинарник работал на разных процессорах.
>
> Зависимости — 22 подключаемых репозитория (git submodule) с закреплёнными SHA. Тесты — 14 наборов, baseline 14 из 14, 0.78 секунды в отладочной сборке и 0.06 секунды в релизе. Дополнительный smoke-тест (runtime smoke) делает 6 эталонных снимков за 1 секунду.
>
> На эталонной сцене Voxel Laboratory: 110–130 кадров в секунду, время кадра 7–9 миллисекунд. Бинарник 73 мегабайта в отладочной сборке и 19 мегабайт в релизе — минус 73 процента. Передаю слово.»

---

## 3. Понятия (10 терминов, чтобы понимать что говоришь)

| Термин | Что это |
|---|---|
| C++26 | Стандарт языка на 2026 год |
| Vulkan 1.4 | Низкоуровневый графический API (наш основной) |
| Clang 22.1.6 | Версия компилятора |
| libc++ 16 | Стандартная библиотека от LLVM |
| CMake 4.0 | Система сборки (build system) |
| LTO (link-time optimization) | Оптимизация при линковке, тонкая = параллельная |
| -ffast-math | Быстрая математика, ломает IEEE 754 — мы НЕ используем |
| -march=native | Оптимизация под текущий CPU — мы НЕ используем |
| ctest | Утилита запуска тестов из CMake |
| smoke (тест) | Сквозная проверка жизненного цикла |

## 4. Что показывать на экране (если попросят)

1. **ctest baseline (~30 секунд):**
   ```bash
   cd /home/le1t/Projects/ProjectV
   ctest --test-dir build/linux-clang-debug --output-on-failure
   ```
   Ожидаемый результат: **14/14 тестов пройдены** за ~0.78 секунды.

2. **Размер бинарника (~10 секунд):**
   ```bash
   ls -lh build/linux-clang-debug/bin/ProjectV
   ls -lh build/linux-clang-release/bin/ProjectV
   ```
   Показывает 73 МБ debug и 19 МБ release.

3. **Runtime smoke (~10 секунд):**
   ```bash
   ls build/linux-clang-debug/lookdev-captures/
   ```
   Показывает каталоги с файлами `.bmp` + `.txt` (эталонные слои).

4. **Список пресетов CMake (~5 секунд):**
   ```bash
   cmake --list-presets=configure
   ```
   Показывает 7 debug + 8 release пресетов.
