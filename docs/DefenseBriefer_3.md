## 2. Что говорить дословно (~150 русских слов, 1:30)

> «Рендеринг в ProjectV построен на Vulkan 1.4, все эффекты в основном проходе, без отдельных screen-space проходов. Расскажу про четыре ключевых эффекта.
>
> Первый — каскадные тени (CSM). У нас 4 каскада карты глубины 2048 на 2048. Лямбда 0.80 — near-biased, близкие объекты получают больше плотности. Стекло не отбрасывает тени, жидкость — отбрасывает. Между каскадами плавный переход.
>
> Второй — контактные тени. Короткая трассировка луча от фрагмента к солнцу, дополняет CSM. Стекло пропускает, жидкость блокирует.
>
> Третий — фоновое затенение (AOCC). Локальное затенение полостей, 12 трассировок на фрагмент. Не полноценный SSAO, а компактный встроенный терм.
>
> Четвёртый — временное сглаживание (TAA). Убирает дрожание камеры. Используем 8-sample Halton-джиттер и YCoCg-зажим. Поверх TAA — CAS, фильтр резкости. F12 — переключение ray-marching, сейчас в режиме заглушки, Phase 7. Передаю слово.»

---

## 3. Понятия (10 терминов)

| Термин | Что это |
|---|---|
| CSM (каскадные тени) | Cascaded Shadow Maps, несколько карт глубины для разных расстояний |
| Каскад | Один диапазон расстояний со своей shadow map |
| Лямбда 0.80 | Параметр баланса near-biased vs uniform распределения каскадов |
| PCF (Percentage-Closer Filtering) | Взвешенное сглаживание теней через сравнения глубины |
| Контактные тени | Трассировка луча от фрагмента к солнцу, дополняет CSM |
| AOCC (фоновое затенение) | Ambient Occlusion Cavity Check, локальное затенение полостей |
| TAA (временное сглаживание) | Temporal Anti-Aliasing, смешивает кадры |
| Halton-джиттер | Квази-случайное смещение для TAA |
| YCoCg | Цветовое пространство, меньше артефактов (ghosting) при clamp |
| CAS (Contrast Adaptive Sharpening) | Фильтр резкости после TAA |

4. **Захват C:** сохраняет .bmp + .txt sidecar, в sidecar 60+ ключей метаданных.
