## 2. Что говорить дословно (~150 русских слов, 1:30)

> «Физика в ProjectV построена на библиотеке Jolt Physics — это современный движок для твёрдых тел, детерминированный, лицензия MIT. Jolt используется для обнаружения столкновений, а наш собственный воксельный решатель дополняет его для опоры игрока.
>
> В игре три режима управления. Walk — обычная ходьба с гравитацией. Creative — полёт с поддержкой столкновений. Spectator — режим наблюдателя, пролетает сквозь стены. Клавиша F4 переключает режимы по кругу, двойное нажатие Space переключает между creative и walk.
>
> У walk-контроллера есть специальные возможности. Допуск тонкого края (edge grace) — контроллер не дёргает игрока на тонких краях. Скрытность (sneak, Shift) — игрок не прилипает к стене за углом. Автопрыжок — игрок автоматически перепрыгивает через блок высотой один, включается клавишей J.
>
> Размещение и удаление блоков — через трассировку луча (raycast): правый клик ставит блок, левый — убирает. Для отладки есть замедление, покадровый шаг, сброс скорости. Передаю слово.»

---

## 3. Понятия (8 терминов)

| Термин | Что это |
|---|---|
| Jolt Physics | Физический движок, MIT, детерминированный |
| Walk mode | Обычная ходьба с гравитацией |
| Creative mode | Полёт с поддержкой столкновений |
| Spectator mode | Наблюдатель, пролетает сквозь стены (noclip) |
| Edge grace | Допуск тонкого края, контроллер не дёргает игрока |
| Sneak (Shift) | Скрытность, не прилипать к стене за углом |
| Auto-jump (J) | Автопрыжок через блок высотой 1 |
| Voxel raycast | Трассировка луча через чанки для placement/removal |

---

## 4. Что показывать на экране

1. **WASD + мышь (walk)** — облёт камеры вокруг сцены, видно гравитацию.
2. **F4 — переключение walk → creative → spectator** — три режима.
3. **Двойной Space — toggle walk ↔ creative** — быстрое переключение.
4. **Левый клик (removal) / правый клик (placement)** — редактирование вокселей.
