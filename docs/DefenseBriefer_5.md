## 2. Что говорить дословно (~150 русских слов, 1:30)

> «Сейчас на экране наша эталонная демо-сцена — Voxel Laboratory. Это пол в виде шахматной доски 18 на 18 вокселей. В центре — стеклянный шар радиуса 6, внутри жидкость. Справа — непрозрачный якорь для стабильных теней. Сцена генерируется процедурно за 200 миллисекунд, это 27 чанков.
>
> Конвейер загрузки ассетов (assets): парсер glTF читает файлы, при наличии сжатия Draco декодирует, meshopt оптимизирует меш для GPU, потом данные загружаются в видеокарту. Манифест моделей задаётся через переменную окружения PROJECTV_MODELS.
>
> Аудио построено на библиотеке miniaudio, формат 16-бит 44.1 кГц стерео, на Linux работает через PulseAudio поверх PipeWire. Плейлист сканируется каждые 5 секунд, новые файлы подхватываются автоматически. Поддерживается только MP3. Управление: Q — воспроизведение, E — стоп, 7 и 8 — громкость, 9 и 0 — следующий и предыдущий трек. Передаю слово ведущему.»

## 3. Понятия (8 терминов)

| Термин | Что это |
|---|---|
| Voxel Laboratory | Эталонная демо-сцена: пол 18×18, шар, жидкость |
| glTF / glb | Формат 3D-моделей (KHR) |
| Draco | Сжатие 3D-мешей (Google) |
| meshopt | Оптимизация мешей для GPU |
| Манифест моделей | Список моделей через переменную окружения |
| miniaudio | Библиотека воспроизведения аудио, header-only |
| PipeWire / PulseAudio | Звуковая подсистема Linux |
| Плейлист | Список MP3-файлов в каталоге `music/` |

## 4. Что показывать на экране

1. **Сцена на экране** — облёт камерой: пол-шахматка, шар, жидкость.
2. **Захват C** — сохранение .bmp + .txt sidecar; в sidecar 60+ ключей метаданных (частота кадров, число вокселей, тени, TAA).
3. **Аудио Q** — play/pause; **9/0** — переключение треков; в папке `music/` два трека.
4. **Cycle views B** — переключение отладочных видов (FINAL/SHDW/CSM/CTSH/AOCC/LOCL).
