Проведено ручное функциональное тестирование runtime приложения и автоматизированное unit-тестирование всех программных модулей \texttt{ProjectV}. Тесты написаны на собственном лёгком фреймворке (\texttt{tests/}): функция \texttt{void\ TestXxx(TestContext\ \&context)}, регистрируется через \texttt{RegisterTest(...)} (см. \texttt{tests/CMakeLists.txt}).

\textbf{Виды тестирования:}

\begin{itemize}
\tightlist
\item
  \textbf{Unit-тестирование} --- \texttt{ctest} запускает 12 suites, \textasciitilde140 test-функций (VoxelWorld 22, FluidCA 10, AssetLoader 10, FrustumCulling 5, BoxUvFixture 2, MeshBaker 4, DracoDecoder 3, Math 1, StringId 1, SunShadowCascadeSplits 1, ModuleSmoke 1, StdModuleProbe 1, плюс ProbeTest и CFrustumCullingTests).
\item
  \textbf{Runtime smoke} --- \texttt{tools/linux/Invoke-ProjectVRuntimeSmoke.sh} (Linux) / \texttt{tools/windows/Invoke-ProjectVRuntimeSmoke.ps1} (Windows) запускает runtime, генерирует 6 captures (FINAL, SHDW, CSM, CTSH, AOCC, LOCL) с sidecar-метаданными.
\item
  \textbf{Профилирование} --- Tracy CPU + GPU zones, sidecar-замеры (\texttt{frame\ time}, \texttt{FPS}, \texttt{GPU\ memory}).
\end{itemize}

\section{Реестр дефектов}\label{KT-2.2_Test_Report-ux440ux435ux435ux441ux442ux440-ux434ux435ux444ux435ux43aux442ux43eux432}

\textbf{BUG-001 --- Закрыт.}

\begin{itemize}
\tightlist
\item
  \textbf{Что:} JPH::\texttt{CharacterVirtual} имел собственный collision query, независимый от \texttt{VoxelWorld} --- на быстром движении (\textgreater{} 30 m/s) walk-персонаж «проходил сквозь стену» в одном кадре.
\item
  \textbf{Решение:} введён \texttt{editVersion} в \texttt{VoxelWorld}; \texttt{CharacterVirtual} синхронизируется перед каждым physics step; полномочия на collision query --- только у \texttt{PhysicsWorld}.
\item
  \textbf{Связь:} детальный post-mortem в \texttt{docs/KT-3.2\_Final\_Report.md} §Post-mortem 1.
\end{itemize}

\textbf{BUG-002 --- Закрыт.}

\begin{itemize}
\tightlist
\item
  \textbf{Что:} \texttt{Vec3} миграция на SIMD ломала компиляцию через ABI-incompatible inline-функции.
\item
  \textbf{Связь:} типы, layout.
\end{itemize}

\textbf{BUG-003 --- Низкий, закрыт.}

\begin{itemize}
\tightlist
\item
  \textbf{Что:} \texttt{SceneResources} не освобождал staging-буфер для неактивного чанка в течение 60+ секунд.
\item
  \textbf{Связь:} утечка памяти GPU.
\end{itemize}

\textbf{BUG-004 --- Средний, открыт.}

\begin{itemize}
\tightlist
\item
  \textbf{Что:} VoxelLab tremor при включённом TAA --- меши слегка дрожат на статичной сцене.
\item
  \textbf{Связь:} descriptor race в TAA pass (см. \texttt{docs/KT-3.2\_Final\_Report.md} post-mortem 3).
\item
  \textbf{Известный обходной путь:} \texttt{PROJECTV\_RENDERER\_TAA=OFF}.
\end{itemize}
