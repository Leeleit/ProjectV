# Practice Specs

This folder contains flat legacy practice/spec documents merged into one navigation layer.

## Status

- `00` to `20` — mostly foundation-oriented implementation notes; still useful as `historical` design references
- `21` and above — mostly `speculative` or post-MVP material

## How To Read This Folder

- treat these files as design sketches, not as a statement of current implementation
- prefer current code and root `docs/` for anything runtime- or workflow-specific
- use these specs when you need historical rationale, naming, or old architecture decomposition

## Known Theme Split

- engine/render/tooling foundation lives in the lower-numbered files
- networking, modding, destruction, CA, non-euclidean geometry, and large future systems live in the higher-numbered files
