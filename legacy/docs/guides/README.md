# Guides

Long-form handbook material restored from the older legacy docs.

## Status

This section is mixed `reference` / `historical`.

- Use `standards/` and `philosophy/` first when you need the current preferred baseline.
- Use `guides/` when you want the broader tutorial-style or handbook-style explanation that did not fit into the
  stricter standards tree.

## Subsections

- `cmake/` — build-system handbooks
- `cpp/` — broad Modern C++ handbook material
- `gameplay/` — gameplay-oriented guidance from the older docs set
- `git/` — workflow and collaboration guides

## Boundary

These guides are intentionally preserved for depth. They may overlap with `standards/`, but they should not override the
current root `TODO.md`, `AGENTS.md`, or the current code.
