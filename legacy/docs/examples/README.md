# Examples

Illustrative code and shader examples that support the legacy docs.

## Status

This section is `historical`.

The examples are preserved because they carry useful reference value, but they do not define the current repository's
active build or runtime contract.

## Scope

- `CMakeLists.txt` and `.cpp` files are preserved as text examples
- shader source files are preserved
- generated `.spv` blobs are intentionally omitted from the unified tree because they are build artifacts, not source

## Use

Treat these files as learning/reference material that complements the legacy docs, especially `libraries/` and
`architecture/`.
