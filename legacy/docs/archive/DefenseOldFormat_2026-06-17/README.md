## Что было неправильно

Эти файлы содержат несколько технических неточностей, отвергнутых оператором в сессии
`2026-06-16T22-23Z-defense-team-script-rebuild-r0`:

1. **BUG-004 (TAA tremor)** — отвергнут. TAA jitter по умолчанию = 0, дрожания нет. BUG-004 был галлюцинацией предыдущей
   сессии.
2. **110-130 FPS, 7-9 мс** — отвергнуто. VoxelLab debug = 500+ FPS, ~2 мс кадр. Старые числа устарели.
3. **12 ctest** — отвергнуто. Реально 14 наборов тестов (baseline 14/14, 0.78 сек debug).
4. **«Создать видимость слаженной командной работы»** — отвергнуто. Оператор сказал: «нам надо красиво подать проект, а
   когда будут задавать вопросы, тут компетенция каждого уже понадобится» — реальные компетенции, не видимость.
5. **macOS в планах** — отвергнуто. macOS нет в roadmap, не упоминаем.
6. **Размер EXE 73→19 МБ как плюс** — отвергнут. Обязанность, а не достижение.
