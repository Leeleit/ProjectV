# agent/

Папка постоянной памяти агента для `ProjectV`.

Эти файлы не декоративные. Любой агент, работающий по проекту, должен читать их в начале заметной сессии и обновлять в конце.

## Состав

- `memory.md` — долгоживущий контекст проекта.
- `status.md` — текущее состояние и ближайшие шаги.
- `decisions.md` — журнал принятых решений.
- `session-checklist.md` — обязательный ритуал старта и завершения сессии.

## Принцип

Если информация важна для следующей сессии, она должна жить не только в ответе пользователю, но и здесь.

Если задача завершена, а `agent/` не обновлён, значит состояние проекта зафиксировано неполно.
