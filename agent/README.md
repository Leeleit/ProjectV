# agent/

Папка постоянной памяти агента для `ProjectV`.

Границы:

- `TODO.md` — roadmap и приоритеты.
- `AGENTS.md` — обязательный протокол.
- `memory.md` — только долговечные repo-specific факты и ограничения.
- `status.md` — короткий снимок текущего фокуса и ближайшего разрыва.
- `decisions.md` — только живые инженерные договорённости.
- `session-checklist.md` — стартовый и финальный чеклист сессии.

`agent/` хранит только delta-контекст; backlog из `TODO.md` и общие правила из `AGENTS.md` сюда не дублируются.
