## 4. Risks

- **Stage 1.1 NanoVDB GPU upload capacity** — initial alloc = 1 upper + 64 lowers + 64 leaves + 64 materials; if flatten result exceeds this, `LogRuntimeFailure` is emitted and version is marked uploaded (skipped upload). For Stage 4.3 (1024+ chunks) may need resize logic.
- **Stage 3.3 Greedy Physics Meshing** — `IsGreedyPhysicsMeshEnabled()` defaults to ON; per-chunk `BuildChunkStaticCollisionBody` now uses greedy merge. Builds take ~2× wall time per chunk (35× fewer AddShape calls = much faster JPH broadphase). Net positive.
- **Stage 4.1 GPU World Gen dispatch (4x wired)** — env gate default ON; `worldGenPipelineEnabled` is true post-init unless shader load fails. Per-frame dispatch fires on non-empty `activeChunkIds`. Build-empty-chunks behavior matches `voxel_lab` scene.
- **Stage 4.3 Chunk Streaming worker (4x wired)** — `std::jthread` joins on `StopChunkStreamerWorker` call (main.cpp shutdown). TSan-clean expected (mutex-protected queues, atomic flag). Risk: file path env var misuse or SSD hang → worker sleeps 1ms loop, no I/O cancellation currently.
- **Stage 2.1 HZB smart mip (4x wired)** — env gate default OFF; 2-phase fallback eliminates 0.02-0.20% FN. mip=0 still safe baseline. risk: SSBO capacity overflow on 1024+ chunks (currently allocated = max(chunks.size(), 1)).
- **Stage 6.3 async compute (this session)** — env gate default OFF (additive optional path per `agent/knowledge.md §30.4`). When ON, Fluid CA + world gen route to dedicated compute queue with 1-frame pipeline depth (graphics in frame N consumes frame N-1's async compute result). HZB stays on graphics CB (cross-queue depth sync deferred — multi-session risk). Risk: timeline counter `renderTimelineValue` is shared between Fluid CA and async pass, so race in counter increment under contention possible if both submits called same frame (currently serialized via `SubmitToComputeQueue` single call).
- **Stage 4.2 LOD GPU consume (this session partial)** — env gate default OFF. SSBO + binding infrastructure in place but actual mesh emission from downsampled payload NOT implemented (GreedyFacePass hardcoded to chunkSize=8). Chunks with `lodLevel > 0` would use full-resolution payload if env ON — visual regression until mesh emission from downsampled added (multi-session work).
- **Stage 4.3 Chunk prebake (this session partial)** — `BakeAllChunksToDisk` API surface in place. Per-frame integration in `FinalizeActiveVoxelWorldReload` + camera-aware drain deferred. Currently API only — not wired to frame loop.
- **Stage 2.1 HZB smart blend width (this session partial)** — CPU helper in place. SSBO struct change + shader consume deferred. Chunks at mip > 0 will continue to use `perChunkMipLevels[]` (1 uint32) SSBO from prior 4x session — no semantic regression.
- **Ninja 1.13 dep-scan race** — `agent/knowledge.md §30` documents the bug workaround (`--parallel 1` first build); required on C++ module changes.
